# FIJI-Macro-foci-quantification
Image analysis to count foci and determine foci intensity of ClpC and its variants was performed in FIJI using a workflow for semi-automated cell detection with the MicrobeJ plugin and a custom macro. In brief, individual regions of interest (ROIs) were created using the Plugin MicrobeJ, using the Triangle thresholding method. Subsequently, fluorescence images were processed using the custom ImageJ/FIJI macro that performs cell-resolved analysis based on the previously defined ROIs. For each cell, a masked image was generated and its intensity histogram computed. To reduce the influence of background and extreme pixel values, a clipped mean intensity was calculated by excluding user-defined lower (10%) and upper (10% for strains with diffuse fluorescence or low-intensity foci, or 30% for cells with large intense foci) fractions of the cumulative pixel distribution. A threshold proportional to this clipped mean was then applied to identify high-intensity regions corresponding to intracellular foci (threshold = 1.7). These regions were segmented, quantified, and associated with their respective cells. In parallel, binary masks and overlay images were generated for visualization. Quantitative outputs, including foci measurements and cell-specific parameters, were exported as a structured results table for further downstream analysis and visualization using a custom R script.
