# FIJI-Macro-foci-quantification
Workflow to threshold a fluorescent microscopy image of a cell based on a clipped mean.
The macro takes one or more fluorescent microscopy images of cells and predefined ROIs as input (obtained from e.g. MicrobeJ or YeastMate). Based on the image of the first channel the cells are segmented individually based on the clipped mean and threshold. The clipped mean is calculated by taking the cells fluorescence intensity histogram, excluding the user-defined lower and upper fractions of pixels, and calculating the mean of the remaining pixels. These values can be adjusted depending on the type of cell and compartment observed. The threshold multiplied to the clipped mean to obtain segmentation of the cells. Each segmented ROI is then measured in each channel and saved to the Results window. This process is repeated for each cell individually. The results file as well as an overlay image and binary image of the segmented ROIs is saved in the results folder. The results file can then be grouped and visualized in a different program (e.g. R, Excel...).
